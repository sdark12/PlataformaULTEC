# sdd-spec-workflow

**Autor:** Equipo Plataforma ULTEC (Skill interna, basada en SDD - Spec-Driven Development)
**Propósito:** Metodología de desarrollo guiado por especificaciones con sintaxis EARS para proyectos grandes. Estandariza el flujo: Spec → Clarificación → Plan → Tareas → Implementación → Validación.

## Cuándo se activa
- Al implementar una nueva característica compleja (más de 2 archivos afectados)
- Al recibir instrucciones ambiguas o incompletas del usuario
- Al planificar refactorizaciones mayores
- Cuando el usuario invoca explícitamente el flujo SDD
