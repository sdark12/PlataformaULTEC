# systematic-debugging

**Autor:** Jesse Vincent / Obra (Superpowers)
**Fuente:** https://github.com/obra/superpowers

Metodología estricta de depuración en 4 fases: Investigar causa raíz → Analizar patrones → Formular hipótesis → Verificar corrección. Prohíbe parches ciegos o arreglos por prueba y error.

## Cuándo se activa
- Al encontrar cualquier bug, falla de test o comportamiento inesperado
- Antes de proponer cualquier corrección
- Cuando un arreglo previo no funcionó
