# local-dates

**Autor:** Equipo Plataforma ULTEC (Skill interna)
**Propósito:** Estandarizar el manejo de fechas y zonas horarias para evitar desfases en cobros, reportes y cortes de mensualidad.

## Cuándo se activa
- Al trabajar con fechas de vencimiento de pagos
- Al calcular cortes mensuales o reportes de antigüedad de deuda
- Al mostrar timestamps en la interfaz de usuario
- Al crear cron jobs o tareas programadas
